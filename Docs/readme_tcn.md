# FFmpeg 腳本 (Windows 批次處理版本)

這是一個簡易的 FFmpeg 腳本，整合了多種音視頻處理功能，支援批次操作，滿足快速處理日常音視頻的需求。

（下載後解壓並將 `bin` 目錄新增至系統 PATH 即可使用）

## 功能特性

- 🎯 **影片轉碼**：支援 H.264、HEVC/H.265、AV1 格式互轉，可自訂編碼設定（如 main/high 等profile）、解析度、位元率等參數。
- ⚡ **硬體加速**：支援 CPU 軟體編解碼，以及 NVIDIA（CUVID/NVENC）、Intel（QSV）、AMD（AMF）顯示卡的硬體編解碼加速。
- 🎞️ **MP4轉GIF**：一鍵將影片轉為動圖，支援自訂解析度（建議較小尺寸）和幀率（建議10-15fps以平衡檔案大小與流暢度）。
- 🎥 **提取影片流**：快速移除影片中的音訊，僅保留影片流（影片直接複製，不重新編碼，速度極快），輸出檔案自動新增 `-without-audio` 後綴。
- 🔊 **音軌/字幕處理**：轉碼時可選擇複製音軌、忽略音軌或自訂音訊參數；字幕支援複製、跳過或自訂處理。
- 📁 **批次處理**：自動讀取 `input` 目錄中所有檔案（忽略 `.gitkeep`），處理後輸出至 `output` 目錄。
- 📊 **進度統計**：每個流程結束後顯示成功/失敗檔案數量，方便排查問題。


## 系統要求

- 已安裝 FFmpeg 並新增至系統 PATH（建議使用上述連結的版本）
- 若使用硬體加速：需對應品牌顯示卡（NVIDIA/Intel/AMD）並安裝最新驅動程式


## 使用方法

### 1. 準備工作
將需要處理的檔案放入 `input` 資料夾中（無需刪除`.gitkeep`檔案，腳本執行時會自動排除）


### 2. 執行腳本
雙擊 `啟動.bat` 啟動腳本，根據主選單提示選擇功能：
- 輸入 `1`：進入影片轉碼流程（可自訂編碼格式、解析度、位元率等）
- 輸入 `2`：進入 MP4 轉 GIF 流程（可調整解析度和幀率）
- 輸入 `3`：進入提取影片流流程（僅保留影片，忽略音訊）


### 3. 依照引導完成設定
根據所選功能的提示，逐步選擇參數（如編碼格式、解析度、幀率等），預設選項可直接按Enter鍵確認。


### 4. 開始處理
確認參數後，腳本將自動批次處理 `input` 目錄中的檔案，結果輸出至 `output` 目錄。


## 目錄結構

```
腳本所在目錄/
│
├── 啟動.bat    # 主腳本檔案
├── input/              # 輸入目錄（存放待處理檔案）
│   ├── .gitkeep        # 佔位檔案（自動忽略，無需刪除）
│   └── 影片檔案.mp4    # 待處理的影片檔案（支援多種格式）
│
└── output/             # 輸出目錄（自動建立）
    ├── 轉碼後的影片.mp4    # 影片轉碼結果
    ├── 動圖.gif           # MP4轉GIF結果
    └── 影片-without-audio.mp4  # 提取影片流結果
```


## 注意事項

1. **硬體加速相容性**：
   - 不同顯示卡對編碼格式的支援不同（如舊款NVIDIA顯示卡可能不支援AV1編碼），不確定時建議選擇CPU軟體編碼。
   - 解碼時若選擇硬體加速失敗，可切換為CPU軟體解碼（相容性最佳）。

2. **GIF轉換建議**：
   - 由於GIF格式限制，建議解析度不超過1080p，幀率10-15fps，避免檔案過大。

3. **檔案格式**：
   - 腳本會處理 `input` 目錄中所有檔案，請確保檔案格式為FFmpeg支援的音視頻格式（如MP4、MKV、MOV等）。

4. **資源佔用**：
   - 影片轉碼（尤其是CPU軟體編碼）可能占用大量系統資源，建議處理時關閉其他占用資源的程式。


## 故障排除

- 若提示「ffmpeg 不是內部或外部命令」：檢查FFmpeg是否正確安裝並新增至系統PATH。
- 硬體加速失敗：嘗試切換為CPU軟體編碼，或更新顯示卡驅動程式。
- 轉換/提取失敗：檢查輸入檔案是否損壞，或嘗試更換參數（如降低解析度、調整位元率）。
- 輸出目錄無檔案：確認 `input` 目錄中是否有非 `.gitkeep` 的有效檔案。
